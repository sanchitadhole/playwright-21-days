# 🎭 Playwright 21 Days Learning Challenge

## 📌 About This Repository

Welcome to my **21 Days Playwright Learning Challenge!**

In this repository, I will document my daily learning, practice programs, and automation testing concepts using Playwright.

My goal is to improve my automation testing skills, build practical knowledge, and prepare for automation testing interviews.

## 🎯 Learning Goals

- Understand Playwright fundamentals.
- Learn to write automated test scripts using JavaScript.
- Practice locators and web element interactions.
- Handle dropdowns, alerts, frames, tabs, and windows.
- Learn assertions, hooks, and test configuration.
- Understand debugging and test reports.
- Practice real-world automation scenarios.
- Prepare for Playwright automation testing interviews.

## ⚙️ Installation and Setup

### 1. Clone the Repository

```bash
git clone YOUR_REPOSITORY_URL
```

Replace `YOUR_REPOSITORY_URL` with your GitHub repository URL.

### 2. Open the Project

```bash
cd playwright-21-days
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Install Playwright Browsers

```bash
npx playwright install
```

### 5. Run Tests

```bash
npx playwright test
```

### 6. View the HTML Report

```bash
npx playwright show-report
```
